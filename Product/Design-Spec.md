# Headly 轻记设计规范

Headly 的视觉围绕低负担记录展开。页面采用暖白底、深墨绿和浅鼠尾草色，标题与数字有适度的衬线变化，操作与说明使用系统字体。装饰同心线条表达时间与节奏，不表示医学数据。

## 页面与组件

两个主页面为今日与回顾；记录以任务浮层打开，详情及隐私是辅助浮层。底栏左右分别切换今日、回顾，中央加号新建记录。底栏常驻，内容纵向滚动。

| 组件 | 样式 | 状态 |
| --- | --- | --- |
| 主卡片 | 深墨绿，28 点圆角，24 点内边距 | 空闲记录入口，进行中摘要 |
| 内容卡片 | 暖白，24 点圆角，18–20 点内边距 | 指标、周视图、记录、说明 |
| 主按钮 | 52–54 点高，16 点圆角 | 正常、反白、禁用 |
| 强度按钮 | 五列两行，高 44 点 | 未选、深色选中 |
| 标签按钮 | 三列，高至少 44 点 | 单选可取消、多选 |
| 记录行 | 左侧强度牌、标题、时间和箭头 | 进行中、已结束 |
| 日历格 | 七列、当前日描边、记录日浅绿 | 未记录、有记录、选中、未来 |
| 错误说明 | 暖红文字，表单内可读 | 字段错误、存储错误 |

## 字体与留白

原生使用系统字体的 serif 与默认设计，中文日期使用 zh_CN locale；浏览器衬线为 Georgia、Songti SC，正文字体为系统 PingFang SC。页面标题 28–34 点，主卡片标题 22–24 点，大指标 32–64 点，主要正文 14–17 点，辅助说明采用 caption。浏览器设计评审微型说明为 9–11 px，后续正式移动版应增加可读尺寸。

间距采用 4 点步长，常用 8、12、16、20、24。外边距 24 点，卡片间距 18–24 点。无常驻横幅、图像背景或强阴影，只有桌面原型画布为手机外框添加投影。

## 交互

选强度需明确点选，避免滑条误触；只显示必要字段，更多信息默认折叠。保存提交成功才关闭，失败保留输入。浮层有未保存修改时关闭需确认。删除和全量清除均确认；导出提醒含健康信息，最终目的地由用户选择。

不使用自动播放、呼吸光、闪动、进度压力或强制打卡。原生过渡沿用 SwiftUI 和系统浮层；浏览器仅使用低动效，遵循减少动画设置。

## 可访问性与适配

信息不只依靠颜色：强度有数字与文字，日期有可读状态，选中控件有语义标签。主要按钮高度大于 44 点，日历七列在 375 宽度下仍需正式版触控验证。浮层滚动且保存操作固定，键盘关闭后可继续编辑。浏览器支持键盘焦点与 Escape；原生最大字号与 VoiceOver 全流程属于发布前实测项目。

基准原型宽度 390–393，验证 375 小屏和桌面评审画布。iPad 当前可运行但不作为首版的独立设计方向，正式发布时需评估是否限制 iPhone 设备家族。
